# Overview
Main goal is to introduce a user-friendly pipeline for others to check on the document-parsing service

document-parsing-service: https://code.in.spdigital.sg/SP-Data-Cloud/document-parser

## Difference between notebook and pipeline

Use notebook if you are testing how the pipeline works and test if you're configuration is correct

Use pipeline if you are confident and want to start your evaluation.
